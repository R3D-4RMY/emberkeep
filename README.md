Emberkeep: Lantern Defense — a tower-defense game. Hold the lantern through 10 waves of invaders with three tower types, upgrades, and a boss on wave 10.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser. Click a build pad to place a tower, Space starts a wave, P pauses, R restarts, F toggles speed, M mutes.
