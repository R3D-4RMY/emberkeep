Emberkeep: Lantern Defense — a tower-defense game. Hold the lantern through 10 waves of invaders with four tower types, upgrades, and bosses on waves 5 and 10.

Pick a difficulty (Chill / Normal / Ember), build towers, and chain kills into a combo for up to x2.00 score and bonus gold. Spark is fast · Ember splashes · Frost slows · Volt Coil chains lightning. Beware the splitting Sparks and the shielded Bulwarks — frost only dents them.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser. Click a build pad to place a tower, Space starts a wave, P pauses, R restarts, F toggles speed, M mutes.
